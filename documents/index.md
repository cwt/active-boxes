# Active Boxes Knowledge Bundle

Active Boxes is a modernized fork of Little Boxes, a tiny ActivityPub
framework written in Python. The project is database and server agnostic,
providing core ActivityPub functionality.

**Modernization goals:**

- Update to Python 3.10+ to leverage modern language features
- Refactor the codebase to modern coding practices
- Create a comprehensive test suite with ~89% coverage
- Ensure full ActivityPub protocol compliance
- Update documentation and create usage examples
